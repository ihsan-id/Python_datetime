PROGRAMIZ DATETIME & TIME - KUMPULAN KODE
==========================================

Sumber: https://www.programiz.com/python-programming/

DAFTAR FILE:
1.  01_python_datetime_module.py       -> datetime module dasar
2.  02_python_strftime.py              -> format datetime ke string
3.  03_python_strptime.py              -> parsing string ke datetime
4.  04_python_current_datetime.py      -> ambil tanggal & waktu sekarang
5.  05_python_current_time.py          -> ambil waktu sekarang
6.  06_python_timestamp_to_datetime.py -> konversi timestamp <-> datetime
7.  07_python_time_module.py           -> modul time
8.  08_python_time_sleep.py            -> time.sleep() & contoh jam digital

CARA PAKAI:
- Jalankan satu per satu: python 01_python_datetime_module.py
- File 01 butuh pytz untuk bagian timezone (opsional): pip install pytz
- File 08 punya infinite loop di jam digital, aktifkan manual.
